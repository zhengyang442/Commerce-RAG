# v0.1 至 v0.4 演进记录

## v0.1：先跑通可评测的稀疏检索

最小链路使用 WANDS 固定数据、SQLite FTS5/BM25、FastAPI、EvidencePack 和只检索降级。480 条冻结查询的 nDCG@10 为 `0.666747`。

这一版首先解决数据下载是否固定、索引能否原子构建、引用是否可核验、未标注结果应如何解释等基础问题。

## v0.2：建立独立向量基线

使用本地 `BAAI/bge-small-en-v1.5` 生成 384 维向量，由 sqlite-vec 检索。nDCG@10 达到 `0.731349`，相对 BM25 提升约 9.69%。

Embedding 模型、revision、模型文件哈希、维度、归一化、数据提交和商品映射摘要进入索引 metadata，避免“同名模型但实际资产不同”。

## v0.3：Hybrid 成为默认，Reranker 保持实验

BM25 Top-50 与 Vector Top-50 使用 RRF `k=60` 融合，Hybrid nDCG@10 达到 `0.747611`，RelevantHit@10 达到 `0.966667`，本机 P95 为 `58.255ms`。

Cross-encoder 将 nDCG@10 进一步提高到 `0.759225`，但 P95 达到 `1,416.331ms`。质量增量不足以抵消交互延迟，因此 Reranker 没有成为默认策略。

## v0.4：中文入口与安全查询理解

增加中文/中英混合语言识别、属性和否定条件提取、价格/库存/配送等数据禁区识别。常见家具表达由本地规则生成英文检索式，只有规则后仍包含未翻译中文时才按需调用已配置 LLM。

30 条冻结中文集上，规则 Top-1 为 `86.67%`、Top-3 为 `96.67%`；全量 LLM Rewrite 分别为 `76.67%` 和 `90%`，且增加约 1.21 秒 P95。因此使用规则优先并不是临时降级，而是当前证据支持的默认方案。

同时加入公网预览边界，但 v0.4 仍是本地应用，不宣称已经完成正式部署。

## v0.5：公开发布版

v0.5 不从增加新算法开始，而是依次完成：

1. 仓库治理、可复现公开证据和 GitHub 作品化；
2. 面向普通访客的 Demo 产品化；
3. Mac mini 自托管、公网隧道和个人网站案例页。

具体边界与验收条件见 [`ROADMAP.md`](../ROADMAP.md)。
